## Описание

`backup.sh` — это простой Bash-скрипт для создания резервной копии указанной директории.

Скрипт создаёт сжатый архив формата `tar.gz`, содержащий указанную директорию. Имя архива содержит текущую дату.

Перед созданием архива скрипт проверяет:
- указана ли исходная директория;
- существует ли исходная директория;
- существует ли директория для сохранения резервной копии.

## Использование

```bash
./backup.sh <исходная_директория> [директория_для_бэкапа]
```

### Аргументы

- `исходная директория` — директория, которую необходимо сохранить. Этот аргумент является обязательным.
- `директория для бэкапа` — директория, в которую будет сохранён архив. Этот аргумент является необязательным.

Если второй аргумент не указан, для сохранения используется директория `/backup`.

## Примеры использования

### С указанием директории для сохранения

```bash
./backup.sh /home/user/Documents /home/user/backups
```

В результате будет создан архив:

```text
/home/user/backups/backup_2026-09-12.tar.gz
```

### Без указания директории для сохранения

```bash
./backup.sh /home/user/Documents
```

В этом случае архив будет сохранён в директорию `/backup`:

```text
/backup/backup_2026-09-12.tar.gz
```

## Возможные ошибки

Если исходная директория не указана:

```text
Error: source directory was not specifed.
Usage: ./backup.sh <source_directory> [backup_directory]
```

Если исходная директория не существует:

```text
Error: source directory does not exist.
```

Если директория для сохранения резервной копии не существует:

```text
Error: backup directory does not exists.
```

При успешном создании резервной копии:

```text
Backup successful: /home/user/backups/backup_2026-09-12.tar.gz
```

Если при создании архива произошла ошибка:

```text
Backup failed!
```
